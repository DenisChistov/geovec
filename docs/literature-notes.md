# Исследования по глобальной геолокации

Эти работы используют разные датасеты и метрики. Их результаты нельзя напрямую сопоставить с нашей случайной выборкой 250 000 снимков.

Исходный PIGEON одновременно использует реальные изображения и дополнительные географические сведения. Здесь его идеи переносятся на разрешённые готовые признаки, без заявления о воспроизведении опубликованной модели.

## Первая проверяемая партия

Пять самостоятельных новых методов, для каждого — отдельная проверка смешивания с V4 с заранее установленным весом 1/3. Каждая проверка использует одинаковые пять внешних фолдов. Это десять новых конфигураций, пять основных архитектур или целей обучения. Их истинное качество устанавливается по WGS84.

## Протокол дальнейшего исследования

- 37 500 исторических тестовых записей остаются закрытыми для подбора.
- Внешняя оценка: пять фолдов, 170 000 в обучении и 42 500 в валидации.
- Подбор и метаобучение выполняются внутри обучающей области; новые производные признаки вычисляются без известных географических координат запроса.
- Каталог содержит исследовательские гипотезы. Метрики записываются только для реально исполненных экспериментов.
- После оценки всех выбранных кандидатных моделей сравниваются несколько совместимых ансамблей на OOF-прогнозах. Итог фиксируется по CV и переобучается на всех 212 500.
- Повторно использованный исторический тест информировал направление исследований через уже известные агрегаты. Для независимой оценки рекомендуется отдельная слепая выборка.
