## Как работает победитель

1. Три нейросети предсказывают распределения по 512, 1 024 и повторно 512 географическим кластерам. Начальные состояния независимы.
2. Из распределений формируются прогнозы Фреше с разными температурами, локальный прогноз по похожим снимкам и прогноз по плотной географической моде. Прямая сеть и обычный поиск соседей дают дополнительный прогноз.
3. Ансамбль разных масштабов служит исходной точкой. Остальные шесть экспертных прогнозов переводятся в смещения на восток и север: `Geod.inv` WGS84 возвращает азимут и расстояние.
4. Контекст состоит из семи признаков: средней нормированной энтропии, недостатка уверенности, среднеквадратичного углового разброса, максимального расхождения экспертов, разброса локальной выборки и двух диагностик поиска. После нормировки формируется произведение каждого экспертного смещения на константу и семь контекстных признаков.
5. Регуляризованная линейная регрессия обучает 48 коэффициентов на 212 500 out-of-fold прогнозах. Используется ridge с относительной регуляризацией 0,024. Затем `Geod.fwd` переносит итоговый вектор поправки на эллипсоид WGS84. Веса могут быть знаковыми, чтобы компенсировать систематические ошибки экспертов.

Веса нейросетей, калибратор и матрица признаков сохраняются отдельно. Поиск по эмбеддингам использует восстановленную из исходного манифеста тренировочную базу `dev_x.npy` и `dev_y.npy`.

## Протокол

Одинаковое разбиение 85/15. Пять внешних фолдов по 42 500, обучение каждого — 170 000. Для обучаемого объединения строятся три внутренних фолда; для финального обучения калибратора используются внешние OOF-прогнозы. Все 50 кандидатов оценены на каждом внешнем фолде. Сортировка по суммарному RMSE WGS84, затем фиксируется победитель. Только победитель получает итоговую оценку на зарегистрированном тесте.

Исторические агрегированные тестовые метрики V1–V3 были известны до V4; этот повторно используемый тест не является новой полностью слепой проверкой. Варианты V4 выбирались только по CV. Обучение базовых сетей и поиск выполнялись на Tesla T4 в Colab; лёгкие геодезические и линейные вычисления также использовали CPU.
